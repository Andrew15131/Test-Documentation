# TC-100: Регрессионный тест модуля оплаты

**ID:** пример из TC-GH-004

**Описание:** Проверить добавление набора тест-кейсов для регрессионного тестирования модуля оплаты.

**Шаги:**
1. Переключиться на ветку с изменениями
2. Открыть форму оплаты и заполнить валидные данные карты
3. Подтвердить оплату
4. Проверить статус заказа и запись в логах/транзакциях

**Ожидаемый результат:** Платёж проходит успешно, заказ создаётся и отображается в истории покупок
