# Тест-кейсы для страницы входа

## TC-001: Успешный вход
**ID:** TC-GH-001
**Предусловия:** Пользователь зарегистрирован

**Шаги:**
1. Открыть страницу `/login`
2. Ввести валидный email
3. Ввести валидный пароль
4. Нажать кнопку "Войти"

**Ожидаемый результат:** Пользователь перенаправлен на главную страницу

---

## TC-002: Вход с невалидным паролем
**ID:** TC-GH-005 (дополнение)
**Предусловия:** Пользователь зарегистрирован

**Шаги:**
1. Открыть страницу `/login`
2. Ввести валидный email
3. Ввести невалидный пароль
4. Нажать кнопку "Войти"

**Ожидаемый результат:** Отображается сообщение об ошибке авторизации; пользователь остаётся на странице входа
