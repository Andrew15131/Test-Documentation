# Тестовая документация проекта PrintMate

## Описание
В данном репозитории хранится тестовая документация:
- Тест-кейсы
- Чек-листы
- Тест-планы

## Структура
- /test-cases — детальные тест-кейсы
- /test-scenarios — сценарии тестирования
- /test-plans — тест-планы на спринты

## Как использовать
1. Перейдите в нужную папку
2. Откройте файл с документацией
3. Для внесения изменений создайте новую ветку и PR
