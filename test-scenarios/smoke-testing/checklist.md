# Чек-лист дымового тестирования

Ниже перечислены 5 базовых проверок для быстрой оценки работоспособности приложения.

1. Открытие главной страницы — страница загружается и отображает основной контент
2. Авторизация — пользователь может войти с валидными учетными данными
3. Критические маршруты — ключевые страницы (главная, логин, профиль) возвращают 200
4. Основной функционал — создание/просмотр основного ресурса (например, создание заказа) работает без ошибок
5. Загрузка файлов — возможность загрузить и скачать простой файл (placeholder)
